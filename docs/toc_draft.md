# 게임서버프로그래밍 목차안 (2026-11-08)

## 이 목차안을 읽는 법

- 기준 학생: 소켓·IOCP로 채팅 프로그램을 만들어 본 정도이고, 실시간 서버를 만들거나 운영해 본 적이 없다. DB는 Workbench로 DB를 만들고 DML과 조인을 해 본 정도이다. 게임 서버 용어(Room, Zone, 분산 서버 등)를 모른다. 그래서 소단원 하나에 개념 하나를 두고, 용어는 필요해지는 자리에서 처음 소개한다.
- 장의 틀: 번호 없는 "장 소개"(학습 목표 포함) → 번호 붙은 본문 → 번호 없는 "학습 정리" → 번호 없는 "연습 문제".
- 표시: `← 현 2.5`는 지금 원고에서 가져오는 곳, `[새로]`는 새로 쓰는 곳, `그림:`은 그 절에 들어갈 그림이다.
- 저자 원문 중 요약형 문장(현 1.2, 1.4~1.9, 4.2~4.5, 5.1~5.6, 6.1~6.7)은 지우지 않고 해당 장의 "학습 정리"로 옮긴다.

## 원문에서 지우는 것

- 현 1.1 "이미 학습한 Windows 네트워크 프로그래밍이나 데이터베이스 개론을 처음부터 반복하지 않는다": 학생 수준에 맞지 않으므로 지운다. 필요한 기초는 해당 장에서 다시 설명한다.
- 현 6.2 "IOCP 서버와 epoll 서버를 각각 재구현하지 않고 Asio를 이용한 통신 모듈을 제작한다": 5장에서 IOCP·epoll 서버를 직접 만드므로 지운다.
- Gateway(현 1.1.1, 1.3, 6.1, 6.5, 6.8의 해당 표현): 방 기반 서버에서는 Lobby가 접속 창구를 겸하므로 별도 서버를 두지 않는다. 관련 표현을 지운다.
